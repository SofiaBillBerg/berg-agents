Shared Todo is a draft for developing plugin system for Berg-Agents.
It is a work-in-progress and subject to change.

## Description

Collaborative planning and todo list for user - agent developement.
This plugin enables user and agent to create, review and edit todo-lists and plans both interactivley and independantly.

It provides a shared tool where an agent can propose a plan and todo-list that also the user can edit and change as needed.
ToDo-lists and plans are saved as markdown documents in sharedtodo directory.
