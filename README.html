Berg Agents

Sofia Billger Bergström

BergAgents — a local, LLM-driven coding assistant with a framework-agnostic core and provider-centric configuration. A multi-agent system built on Pydantic AI: Guardian, Planner, Implementation, Curator and Learning agents run a harness-based execution model with human-in-the-loop approval gates. Any OpenAI-compatible provider works with zero code changes, surfaced through an interactive TUI and a Next.js + FastAPI web UI that share the same commands and task lifecycle.

Quick Start

# Install dependencies (uv is recommended)
uv venv .venv
source .venv/bin/activate
uv pip install -e .

# Interactive terminal UI
python -m berg_agents --tui

# Web UI (default: http://127.0.0.1:8001)
python -m berg_agents --web

Full walkthrough: QUICKSTART.

What it is

  • Harness engine — Guardian (risk gate) → Planner (breakdown) → Implementation (edits) → Curator (review), plus Learning stats. See USAGE.
  • Provider-centric config — each model carries its own provider, baseURL and apiKey. No global provider flag. See CONFIGURATION.
  • Real plugin system — discovery, capabilities, generic tool dispatch, and plugin-owned UI bundles. Pilot: shared-todo. See Shared-ToDo and Plugin UI.
  • Memory that persists — a MEMORY.md notebook injected every request, tiered compaction, step persistence with keyword recall. See MEMORY.
// {config}/bergagents.jsonc — providers, harness, routing, plugins
{
  "providers": {
    "ollama": {
      "options": { "baseURL": "http://localhost:11434/v1", "apiKey": "" },
      "models": { "qwen3.5:9b": {} }
    }
  },
  "harness": { "enable_learning": true, "enable_hitl": true },
  "defaultModel": "qwen3.5:9b"
}

Secrets live in .env as ${env:VAR_NAME} references — never inline. The config directory resolves via BERG_AGENTS_CONFIG_DIR → .berg-config → .berg-agents → ~/.berg-agents.

Configuration

{config}/bergagents.jsonc   # providers, harness, model_routing, hitl_rules, plugins, agents
.env                        # secrets referenced as `${env:VAR_NAME}`
Layer Source
Config file {config}/bergagents.jsonc — providers block plus harness / model_routing / hitl_rules / plugins / agents
Secrets .env file, referenced with ${env:VAR_NAME}
Overrides BERG_AGENT_* environment variables
External tools {config}/mcp.json for MCP server configuration
